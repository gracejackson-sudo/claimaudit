claimaudit

A first-pass checker for the claims, numbers and citations in a folder of documents.

What it is

claimaudit reads the Markdown, LaTeX, text, BibTeX, notebook and Word files in a folder and lists sentences a person should look at: wording such as "we are the first" or "proven", numbers that do not match the data files beside them or disagree between documents, citations that do not resolve, and arithmetic in a sentence that does not add up. It does not decide whether anything is true, and it will miss most of what a careful reader would catch. It runs locally, uses only the Python standard library, and uploads nothing.

What it has been measured to do

These are small samples. They are reported as they came out, not rounded up.

  • Frozen corpus of eight known errors: it catches 3 of 8. It reaches 4 of 8 only if the author tags claims and supplies a registry of the values their own pipeline computed. The original replay cannot be re-run; a reconstruction of the eight errors is checked in with tests to catch drift, not as independent evidence.
  • Fifteen third-party ML papers, the free overclaim check: after the latest changes, flags fell from 670 to 110. Of 60 sampled flags, 3 were correct, which is 5% precision. A sample of 60 cannot distinguish that from the 1.7% measured before those changes. Most of what it flags is fine. Treat its output as a reading list, not a verdict.

Install

claimaudit is not on PyPI; pip install claimaudit will not find it. Install from a copy of the source folder (the page you land on after payment says where to get it). Python 3.9 or newer, no dependencies: 

cd claimaudit
python3 -m pip install -e .
claimaudit check path/to/folder

If the claimaudit script is not on your PATH, this does the same thing:

python3 -m claimaudit check path/to/folder

To unlock the paid checks with the key from that page:

claimaudit activate YOUR-KEY
claimaudit status

In CI, set CLAIMAUDIT_LICENSE_KEY in the environment instead.

How the license works

It is an honor system. The key is a shared token shown to you after purchase, not a cryptographic license. claimaudit activate stores it on your machine and sends nothing anywhere. Any non-empty key unlocks the paid checks, and no server ever checks it. Anyone who reads the code can bypass it. If the tool is useful to you, please pay for it.

Limitations

  • Precision over recall. It stays quiet unless it has something to compare against, so it misses far more than it flags.
  • Honor-system license. No server validates the key.
  • No license server and no telemetry. By default the only network requests are the citation lookups (arXiv, Crossref, and URLs in your documents), and --offline turns those off. The experimental support check, which you have to ask for by name, also downloads the cited papers.
  • No language model by default. None of the checks uses one unless you add the experimental --llm option to the experimental support check, which sends a sentence and excerpts of the cited paper to the Anthropic API. That option has not been validated against a live model. Nothing is sent unless you pass it.
  • It treats all prose as the author's voice. Quoted text, prompt exemplars, dataset rows and model-generated samples are audited as if the author asserted them, so they can be flagged. Use --exclude on those files.
  • PDFs are not read. Text inside a PDF pulled in with \includepdf is not read; the tool says so rather than reporting a clean result.
  • The citation check resolves identifiers. It does not check that the cited paper supports the sentence citing it. The experimental support check tries to, and can only catch a few kinds of mistake.

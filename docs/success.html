Install

claimaudit is not on PyPI; pip install claimaudit will not find it. Install it from the source repository. You need Python 3.9 or newer; there are no other dependencies.

Repository: https://github.com/gracejackson-sudo/claimaudit

git clone https://github.com/gracejackson-sudo/claimaudit.git claimaudit
cd claimaudit
python3 -m pip install -e .
claimaudit activate claimaudit-early-2026
claimaudit check path/to/folder

If the claimaudit script is not on your PATH, this does the same thing:

python3 -m claimaudit activate claimaudit-early-2026
python3 -m claimaudit check path/to/folder

claimaudit status shows which tier you are on; after activating it should say paid. activate writes the key to ~/.claimaudit/license.json and sends nothing anywhere. In CI, set CLAIMAUDIT_LICENSE_KEY=claimaudit-early-2026 in the environment instead.
